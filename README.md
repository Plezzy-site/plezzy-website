# PLEZZY — Modern Intimacy Essentials

Thoughtfully designed everyday essentials for modern intimacy.

## 🚀 Overview
PLEZZY is an editorial luxury e-commerce experience featuring:
- **Cinematic Visual Experience:** High-definition video banners, iridescent foil textures, and tactile product showcases.
- **Dynamic Product Carousel:** High-impact horizontal slideshow with continuous rightward animation and interactive hover-to-pause controls.
- **Full Mobile Responsiveness:** Edge-to-edge mobile presentation optimized for touch interactions.
- **Interactive PDP Modals & Cart Engine:** Real-time bag management, secure checkout flows, and address/order state handling.
- **Multi-network Mobile Previews:** Built-in LAN IP detection and live cloud tunnel integration for instant testing on any mobile phone.

## 🛠️ Tech Stack
- **Frontend:** Vanilla HTML5, Modern ES Modules, Tailwind CSS / Custom Luxury Editorial Design System
- **Backend / API Service:** Node.js HTTP server (`server.cjs`), file-based order & catalog database (`backend.cjs`)
- **Typography:** Swiss, Rektorat Heavy, Plus Jakarta Sans, Playfair Display, Cormorant Garamond

## 📦 Getting Started

### 1. Prerequisites
- Node.js (v18 or higher recommended)

### 2. Installation
```bash
npm install
```

### 3. Run the Development Server
```bash
node server.cjs
```
This will start the local server at:
- **Local:** `http://localhost:3000`
- **Wi-Fi / LAN:** `http://<your-ip>:3000`
